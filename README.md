Hi, this is my Task Management Web Application 👋

This is a full-stack Task Management web application where users can create, update, delete, and manage their daily tasks efficiently. The application helps users stay organized and improve productivity with a simple and clean interface.

This project is built using modern full-stack technologies with a focus on scalability, performance, and user experience.

🌐 Live Project: https://task-0925.onrender.com/

---

## 🛠 Tech Stack
- React.js (Frontend)
- Node.js (Backend)
- Express.js (Server)
- MongoDB (Database)

---

## ✨ Features
- Add new tasks
- Update existing tasks
- Delete tasks
- Task status management
- Responsive and user-friendly UI
